# PROYECTO-DE-ALGORITMOS-LUIS-GONCALVES-STEPHANY-LAGOS-Y-YONATHAN-PE-A
MeteoCaracas es un sistema de monitoreo y consulta del clima en tiempo real e histórico diseñado para el área Metropolitana de Caracas. El proyecto está desarrollado estrictamente bajo el enfoque de la Programación Orientada a Objetos (POO) en Python, integrando herramientas de análisis de datos y visualización gráfica.
